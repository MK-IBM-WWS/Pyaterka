# Пятерка — голосовой помощник кафедры ИУ5

Страница Пятерки открывается по DNS-имени, например `https://pyaterka.example.org/`. Посетитель подключает микрофон и задаёт вопрос. Слева появляется короткая реплика, которую озвучивает полярная сова Пятерка. На иллюстрации справа сова наклоняет голову, когда слушает, и чешет висок крылом, когда обдумывает ответ. Во время ответа клюв двигается в такт звуку. Панель звука и микрофона можно свернуть даже во время разговора.

## Сервер

| Компонент | Где работает | Назначение |
| --- | --- | --- |
| Qwen3.6‑27B IQ4_XS, llama.cpp CUDA 12 | Tesla V100 16 ГБ | Генерация ответа. Текстовая модель, контекст 4096 токенов, один слот генерации |
| Whisper Large v3, CTranslate2 INT8 | CPU | Русское распознавание речи после паузы. Silero VAD определяет начало и конец реплики |
| Silero TTS v5.6 RU, голос Baya | CPU | Озвучивание с автоматическими ударениями и нормализацией чисел, времени и обозначений групп |
| BAAI/bge-m3, SQLite FTS5/BM25 | CPU | Векторный и полнотекстовый поиск по базе с русским стеммингом |
| LiveKit, Nginx, Redis, веб-сервер | CPU | WebRTC, HTTPS/WSS, авторизация администратора и выдача токенов |

Целевой сервер — Debian 13 amd64, i7‑12700K, 96 ГБ RAM и V100 16 ГБ. Для первого запуска потребуется интернет для образов и весов. Веса по умолчанию занимают около 21 ГБ. Оставьте 35–45 ГБ свободного места для них, образов и сборки. После подготовки моделей поиск, распознавание, генерация и озвучивание идут локально. Веб-клиент использует включённые в архив JavaScript-библиотеки.

Файл IQ4_XS весит 15,4 ГБ в десятичных единицах. Дополнительно расходуются память на контекст, вычислительные буферы и CUDA. Если на конкретной V100 профиль не помещается, воспользуйтесь профилем UD-Q3_K_XL ниже. Сколько памяти доступно, зависит также от ECC и других процессов на GPU. На V100 используется CUDA 12 и драйвер с поддержкой Volta. Для выбранного образа CUDA 12.8 с JIT-компиляцией кода для Volta используйте драйвер от 570.124.06 с поддержкой V100, например проприетарный драйвер ветки 580. Используйте проприетарный модуль NVIDIA для Volta. Для Silero TTS соблюдайте условия лицензии [CC BY-NC 4.0](https://github.com/snakers4/silero-models#license).

## Установка на Debian 13

1. Установите подходящий драйвер NVIDIA, убедитесь, что `nvidia-smi -L` видит V100. Если Docker ещё не установлен, установите его из Debian.

   ```bash
   sudo apt update
   sudo apt install docker.io docker-compose
   sudo systemctl enable --now docker
   ```

2. Установите [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html#with-apt-ubuntu-debian), настройте Docker и проверьте доступ к GPU из контейнера.

   ```bash
   sudo nvidia-ctk runtime configure --runtime=docker
   sudo systemctl restart docker
   sudo docker run --rm --gpus all ubuntu:24.04 nvidia-smi
   ```

3. Распакуйте архив и передайте DNS-имя сервера. Имя должно разрешаться в актуальный IPv4 на сервере и на клиентских устройствах. При динамической выдаче адресов DNS-запись должна обновляться средствами сети. Если запустить `bash install.sh` без аргументов при первой установке, скрипт запросит DNS-имя.

   ```bash
   cd ai-voice-loc
   bash install.sh pyaterka.example.org
   ```

   Для доверенного сертификата укажите локальные пути к цепочке сертификатов и ключу.

   ```bash
   TLS_CERT_FILE=/path/fullchain.pem \
     TLS_KEY_FILE=/path/privkey.pem bash install.sh pyaterka.example.org
   ```

   При публичном DNS, доступном порте 80 и доступе к ACME можно передать `LE_EMAIL=admin@example.org` при первом или повторном запуске. Установщик выпустит сертификат Let's Encrypt. Для продления запускайте `docker compose run --rm certbot renew && docker compose exec -T nginx nginx -s reload` из каталога проекта. При самоподписанном сертификате добавьте `nginx/ssl/self-signed/pyaterka.example.org/voice.crt` в доверенные сертификаты клиентских устройств, подставив своё DNS-имя. Браузер должен считать HTTPS-сайт доверенным, чтобы предоставить доступ к микрофону.

4. Проверьте контейнеры и откройте сайт.

   ```bash
   docker compose ps
   docker compose logs --tail=70 llm inference agent
   ```

   В журнале `llm` проверьте, что определяется CUDA0 и слои выгружены на GPU. На хосте проверьте загрузку GPU через `nvidia-smi`. Путь `/v1/health` на сайте Пятерки показывает доступность LiveKit, CPU-сервиса и LLM.

Установщик сохраняет настройки и пароли в `.env` с правами 600. Посетитель входит как `visitor` с паролем `WEB_PASSWORD`. Если в кафедральной сети нужен вход без пароля, задайте `PUBLIC_AUTH=off` и повторите `bash install.sh`. Отдельный вход в `/admin/` использует `RAG_ADMIN_USER` и `RAG_ADMIN_PASSWORD`. Для смены пароля или других параметров обновите `.env` и повторите установщик. При ошибке об отсутствии прав выполняйте команды Docker через `sudo`.

Разрешите на сетевом экране TCP 443 для HTTPS и WSS, UDP 50000–50100 и TCP 7881 для WebRTC. TCP 80 нужен для HTTP-перенаправления и ACME. Если между посетителями и сервером есть NAT, пробросьте эти порты и убедитесь, что DNS-имя ведёт на адрес, достижимый участниками WebRTC. Сигналинг WebRTC проходит через Nginx. Внутренний TCP-порт 7880 доступен служебным контейнерам. В сетях, где недоступен и прямой UDP, и TCP 7881, потребуется отдельно настроить TURN.

LiveKit получает адрес для WebRTC из DNS при старте и проверяет запись каждые 15 секунд. После обновления DNS и его кэша LiveKit перезапустится с новым адресом. Открытый голосовой сеанс может прерваться, тогда подключитесь снова по тому же имени. При переносе установки с числового адреса обновите исходники в существующем каталоге и запустите `bash install.sh pyaterka.example.org`. Установщик запишет DNS-имя в `.env` и сохранит остальные настройки.

### Диагностика APT

Установщик обращается к APT, только когда на сервере отсутствуют нужные утилиты. Для загрузки моделей подходит рабочий `curl` или `wget`. Если все зависимости Пятерки уже на месте, повторите запуск обновлённого `install.sh`.

При ошибке `Unmet dependencies` обновите индексы и посмотрите, какое исправление предлагает APT.

```bash
sudo apt update
apt-cache policy curl libcurl4t64 jq squashfs-tools
sudo apt-get -s --fix-broken install
```

В выводе симуляции проверьте список пакетов на удаление. Если предложенные изменения подходят, выполните `sudo apt-get --fix-broken install` и повторите установку. Если APT по-прежнему предлагает разные версии `curl` и `libcurl4t64`, сравните их доступные версии и источники в выводе `apt-cache policy`. Состояние удержания пакетов можно посмотреть командой `apt-mark showhold`.

### Если V100 не хватает видеопамяти

В `.env` измените имя модели и при необходимости контекст. Повторный запуск установщика скачает выбранные веса и применит конфигурацию.

```dotenv
LLM_FILE=Qwen3.6-27B-UD-Q3_K_XL.gguf
LLM_CONTEXT=3072
```

```bash
bash install.sh
docker compose logs --tail=80 llm
nvidia-smi
```

Для другого GPU укажите его индекс или UUID в `LLM_GPU_DEVICE`. Настройки `TORCH_CPU_THREADS=4` и `WHISPER_CPU_THREADS=8` задаются в `.env`. Для смены голоса задайте `TTS_SPEAKER` в `.env`, например `TTS_SPEAKER=kseniya`, затем выполните `docker compose up -d inference`. До трёх голосовых комнат допускаются по умолчанию. Генерации в одном слоте GPU идут по очереди.

## Заполнение базы знаний

Админка открывается на сайте Пятерки по пути `/admin/`. База при первом старте пуста. Через интерфейс можно добавить, отредактировать и удалить запись, загрузить текст из TXT/MD, импортировать набор JSON и выгрузить всю базу в JSON. Для обычного наполнения заведите одну запись на преподавателя, одну на объявление и одну на группу или день расписания. Запись может содержать любой текст. Поле «Действует по» включительно. Для расписания укажите период семестра, а для объявлений — срок актуальности, если он известен. Просроченные записи остаются в списке администрирования и исключаются из поиска Пятерки.

Импорт принимает массив до 200 записей за раз. Совпадение категории и заголовка обновляет существующую запись. Максимальный размер текста одной записи — 24 000 символов. Пример структуры на вымышленных данных.

```json
[
  {
    "title": "Расписание тестовой группы ИУ5-00Б, понедельник",
    "category": "schedule",
    "content": "Тестовое занятие проходит в понедельник с 10:15 до 11:50 в аудитории 000.",
    "source": "Демонстрационный пример",
    "valid_from": "",
    "valid_until": ""
  }
]
```

Категории в JSON — `teacher`, `schedule`, `announcement` и `other`. В расписание удобно включать группу, дисциплину, день, время, аудиторию и даты либо привязку к чётной и нечётной неделе. Для вопросов о чётности конкретной недели включите в справку её календарное определение или сами даты занятий. Пятерка получает максимум четыре найденных фрагмента и инструкцию сообщать, когда сведений для кафедрального ответа не хватает. После заполнения проверьте вопросы по фамилиям, номеру группы, времени занятия и объявлению.

Данные хранятся в Docker volume `rag-data`. Для резервного копирования воспользуйтесь экспортом в админке. Скрипт `bash uninstall.sh` останавливает и удаляет контейнеры с сохранением базы, весов, сертификатов и настроек.

## Интерфейсы и исходники

- `GET /token?room=...` выдаёт токен браузеру. Вход посетителя контролируется Nginx.
- `GET /v1/token?room=...` и `GET /v1/metrics` принимают `Authorization: Bearer <CLIENT_API_KEY>`. Токен разрешает подписку и публикацию микрофона.
- `agent/myagent.py` связывает LiveKit и модели. `agent/department.py` ограничивает ответ 45 словами и 320 символами.
- `inference/knowledge.py` содержит индекс и поиск. `web/admin.html` и `web/static/admin.mjs` обслуживают редактирование.
- Изображения Пятерки лежат в `web/static/avatars/`. CSS-анимации в `assistant.css` двигают голову и крыло. `web/static/owl.mjs` связывает клюв с уровнем звука. Настройка браузера «Уменьшить движение» оставляет статичные позы.
- Внутренние API эмбеддера, речи и LLM доступны в отдельной сети Docker без внешнего маршрута.
